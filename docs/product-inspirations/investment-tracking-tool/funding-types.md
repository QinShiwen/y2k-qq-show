# 基金类型 & 分析

## 货币市场基金

**收益来源**：短期存款、国债、同业存单、商业票据等产生的利息。

**本质**：现金管理工具，几乎不追求资本增值。

**分析重点**：

- **持仓结构**：存款、国债、金融债、企业短期票据各占多少？评级是否高（AAA/AA 级为主）？
- **加权平均剩余期限**：越短，利率变化影响越小，流动性越好（通常控制在 120 天以内）。
- **费用**：管理费越低越好（0.1%–0.3% 较理想）。
- **实际净收益率**：对比同类美元/港元货币基金、银行美元定存利率。
- **汇率风险**（如果是美元基金的港币份额）：港币兑美元波动会影响你的港币回报。

**操作步骤**：

1. 在富途看「持仓明细」或「资产配置」。
2. 搜索基金公司官网最新月报/季报，看前十大持仓和评级分布。
3. 对比同类产品的 7 日年化或近 1 月年化收益率。

**判断标准**：净收益能稳定高于银行同类存款，且费用低、持仓信用质量高 → 值得作为闲钱停泊。

## 债券型基金

**收益来源**：债券利息 + 债券价格波动（利率下降时价格上涨）。

**本质**：借钱给政府/企业，赚利息，兼有一定资本利得。

**分析重点**：

- **久期（Duration）**：久期越长，对利率变化越敏感（利率升 → 净值跌）。
- **信用质量**：国债/政策性金融债 vs 高收益债（垃圾债）比例。
- **杠杆水平**：有些债券基金借钱加杠杆，收益和风险都会放大。
- **派息来源**：是真正利息，还是侵蚀本金？
- **与基准对比**：是否长期跑赢对应债券指数。

**操作步骤**：

1. 看基金详情页的「久期」「平均信用评级」。
2. 查看最新季报的行业/信用评级分布。
3. 对比同类债券基金的夏普比率和最大回撤。

**判断标准**：久期匹配你的持有期、信用质量高、费用合理、长期能跑赢基准 → 可考虑。

## 股票型基金（主动管理）

**收益来源**：股票涨跌 + 分红。

**本质**：间接持有一篮子公司。

**分析重点**：

- **前十大重仓股**：是哪些公司？你是否了解它们的商业模式、竞争优势、行业前景？
- **行业集中度**：是否过度集中在单一行业（如科技、消费）？
- **基金经理风格**：价值、成长、均衡？风格是否稳定？换经理频率？
- **换手率**：过高说明频繁交易，成本高、风格可能不稳。
- **历史业绩**：3–5 年是否稳定跑赢基准和同类，同时回撤可控。

**操作步骤**：

1. 富途查看「持仓」→ 前十大股票及占比。
2. 对重仓股简单搜索：公司做什么、近期业绩、市场评价。
3. 看基金经理简历和过往管理产品的长期表现。
4. 对比同期沪深 300 / 中证 500 / 行业指数的表现。

**判断标准**：

- 你能大致理解前十大公司在做什么，并且认可它们的长期价值。
- 经理风格清晰、长期业绩不差、回撤你能接受。

→ 才值得认真考虑。

如果完全看不懂重仓股，或者高度集中在你不了解的行业，风险会显著上升。

## 混合型 / 平衡型 / 收益增长型

**收益来源**：股票上涨 + 债券利息 + 可能的另类资产。  

**本质**：股债搭配，追求「收益+增长」。

**分析重点**：

- **股债比例**：实际股票仓位大概多少？（常见40%-70%）
- **总回报**（净值变化 + 已派股息）：不能只看派息率。
- **派息可持续性**：是来自利息/股息，还是经常动用本金？
- **最大回撤**：股市大跌时跌了多少？
- **资产配置灵活性**：经理会不会大幅偏离既定股债比例？
- **费用**：主动多资产基金费用通常较高（1%-1.6%），需要持续创造超额回报才能覆盖。

**操作步骤**：

1. 看最新季报的资产配置饼图。
2. 计算近1年、3年的「总回报」（含派息）。
3. 对比简单的60/40组合或同类平衡基金表现。
4. 关注派息后净值是否长期走低（可能侵蚀本金）。

**判断标准**：总回报能跑赢同类、回撤在你承受范围内、派息相对稳定 → 可作为核心配置之一。

案例：PIMCO GIS收益增长基金
